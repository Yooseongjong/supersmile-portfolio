# SuperSmile Creative

A "Deep Dark & Cinematic" portfolio website for a visual production agency.

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features

- 🎥 **Cinematic Experience**: Immersive dark mode design with smooth parallax effects.
- ⚡ **Performance**: Optimized images and efficient code splitting.
- 🔊 **Audio Interaction**: Subtle sound effects on user interaction (hover/click) using the Web Audio API.
- 📱 **Responsive**: Fully responsive layout for all devices.
- 🔍 **SEO Optimized**: Dynamic metadata, sitemap, and structure for search engines.

## Development

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router pages and API routes.
- `components/`: Reusable UI components and sections.
- `lib/`: Utility functions and static data.
- `public/`: Static assets (images, fonts, robots.txt).
